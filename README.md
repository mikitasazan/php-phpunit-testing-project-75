# Тестирование загрузчика страниц (PHP)

[![hexlet-check](https://github.com/mikitasazan/php-phpunit-testing-project-75/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/mikitasazan/php-phpunit-testing-project-75/actions)

Загрузчик страниц – библиотека, которая умеет скачивать страницы по сети и сохранять их на локальном диске. Акцент в проекте делается на ее тестировании. Из-за обилия побочных эффектов, здесь придется правильно работать с их подавлением, стабами/моками и возможными ошибками.

Учебный проект Хекслета: https://ru.hexlet.io/programs/php-phpunit-testing
Как это должно работать: https://asciinema.org/a/T6FdZseTOMx2iYKLEK6orHdz9
